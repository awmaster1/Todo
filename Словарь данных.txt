Таблица 1: Users (Пользователи)
Поле	            Тип данных	Обязательно	Описание	                                            Пример
Id	                int (PK)	    Да	    Уникальный идентификатор пользователя	                1
Username	        nvarchar(100)	Да	    Имя пользователя	                                    "Alex"
Email	            nvarchar(255)	Да	    Электронная почта	                                    "pangcheo1210@gmail.com"
Password	        nvarchar(100)	Да	    Пароль (в реальном проекте должен быть хеширован)	    "123456"
RegistrationDate	datetime	    Да	    Дата регистрации	                                    2024-01-17 14:30:00
IsActive	        bit	            Да	    Флаг активности пользователя	                        1


Таблица 2: UserTasks (Задачи пользователей)
Поле	        Тип данных	    Обязательно	       Описание	                                Пример
Id	            int (PK)	    Да	               Уникальный идентификатор задачи	        1
UserId	        int (FK)	    Да	               Ссылка на пользователя	                1
Title	        nvarchar(255)	Да	               Название задачи	                        "Сделать домашнее задание"
Description	    nvarchar(MAX)	Нет	               Подробное описание задачи	            "Сделать упражнения 1-10 по математике"
Date	        datetime	    Да	               Дата создания задачи	                    2024-01-17
Time	        nvarchar(50)	Нет	               Время выполнения задачи	                "9:00 am"
Category	    nvarchar(50)	Да	               Категория задачи	                        "Учеба"
IsCompleted	    bit	            Да	               Статус выполнения                        (0/1)	0
CreatedAt	    datetime	    Да	               Дата и время создания записи	            2024-01-17 14:35:00
